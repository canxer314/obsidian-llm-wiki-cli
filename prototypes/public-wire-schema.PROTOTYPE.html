public wire contract 决策实验台

问题不是“能否写出一大份 JSON”，而是：一个版本化 contract source 能否同时约束六个已确认 MCP 工具、候选 diagnostics、兼容规则和跨调用测试，又不让 JSON Schema 冒充它证明不了的时间、身份、恢复和字节语义。

当前假设，不是最终答案

一个 source of truth 可行，但它应是版本化 contract package：每个工具有独立 strict input/output root，共享已决 $defs；同一 package 还命名 fixtures 与跨调用 contract scenarios。若“一个 JSON Schema”被理解成“Schema 关键字单独证明全部行为”，答案是否定的。
