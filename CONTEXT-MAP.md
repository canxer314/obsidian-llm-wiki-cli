# Context Map

## Contexts

- [Vault Operations](./CONTEXT.md) — defines reliable agent access to the Primary Operator's Obsidian vault
- [AFK Delivery](./docs/contexts/afk-delivery/CONTEXT.md) — coordinates autonomous implementation, review, repair, and merge work across machines

## Relationships

- **AFK Delivery → Vault Operations**: AFK Delivery may deliver changes to the Vault Operation Bridge, but it treats Vault Operations requirements as ticket specifications rather than redefining that domain's language.
